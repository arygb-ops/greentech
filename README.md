# greentech
# 🌱 Ağıllı Torpaq Həkimi

**Süni intellekt əsaslı torpaq monitorinqi və ağıllı suvarma sistemi**

---

## 🎯 Layihəyə Baxış

Smart Soil Doctor, torpaq şəraitini real vaxt rejimində izləmək və suvarmanı avtomatik olaraq optimallaşdırmaq üçün hazırlanmış ağıllı kənd təsərrüfatı sistemidir. Məqsəd su israfını azaltmaq, torpağın sağlamlığını yaxşılaşdırmaq və məhsuldarlığı artırmaqdır.

---

## ❗ Problem

Bir çox kənd təsərrüfatı sahələrində fermerlərin torpaq şəraiti haqqında real vaxt məlumatlarına ehtiyacı var. Nəticədə:

* Su çox vaxt həddindən artıq və ya az istifadə olunur
* Torpağın keyfiyyəti düzgün olmayan müalicə səbəbindən pisləşir
* Məhsuldarlıq azalır

---

## 💡 Həll yolu

Bu layihə, suvarmanı səmərəli idarə etmək üçün sensorları və ağıllı qərar qəbuletməni birləşdirən ağıllı bir sistem təqdim edir. Sistem torpaq məlumatlarını toplayır və nə vaxt və nə qədər suya ehtiyac olduğunu avtomatik olaraq müəyyən edir.

---

## ⚙️ Necə işləyir

* Torpaq sensorları nəmliyi, temperaturu və digər parametrləri ölçür
* Məlumatlar emal olunur və təhlil edilir
* Sistem suvarmanın tələb olunub-olunmadığına qərar verir
* Su təchizatı avtomatik olaraq idarə olunur

---

## 🖥️ Dashboard-u sayt kimi açmaq

### Tələblər

- Node.js 18+ (və ya daha yeni)

### Addımlar

```bash
npm install
npm run dev
```

Brauzerdə bu ünvanı açın:

- `http://localhost:5173`

Prod build üçün:

```bash
npm run build
npm run preview
```

---

## 🔥 İnnovasiya

Ənənəvi monitorinq sistemlərindən fərqli olaraq, Smart Soil Doctor yalnız torpaq vəziyyətini izləmir, həm də gələcək torpaq sağlamlığını proqnozlaşdırır və resurslardan istifadəni optimallaşdırmaq üçün müstəqil qərarlar qəbul edir.

---

## 🛠️ İstifadə olunan texnologiyalar

* Arduino mikrokontrolleri
* Torpaq nəmlik sensoru
* Temperatur sensoru
* Su nasosu və idarəetmə modulu
* React + Vite (dashboard web interfeysi)
